# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting or security advisory flow for this repository when available. Include enough detail to reproduce the issue without including live credentials, tokens, or other secret values.

The project treats repository assurance as read-only by default. Reports involving unexpected mutation, secret disclosure, incorrect PASS results under incomplete evidence, or audit conclusions bound to the wrong commit are considered security-relevant.

## Supported versions

Until the project has tagged stable releases, only the current default branch is considered supported.
